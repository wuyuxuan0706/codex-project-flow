# Codex 项目协作规则

适用于整个 `<PROJECT_NAME>` 项目；更深目录的 `AGENTS.md` 可增加局部规则。

## 项目事实

- 只记录少量、稳定且影响实施判断的事实；未知内容不得猜测。

## Work、请求与执行

- “项目事实”节和 `docs/PROJECT_STATE.md` 属于项目内容，升级时保留；其他托管内容采用新版。
- Work 只分析、澄清和设计。执行前确认目标、范围、不做项、环境、验收与授权；范围变化时暂停执行并回到中枢确认，确认后优先继续原任务，不自动新建任务。
- 每个获批请求最多创建一个用户可见执行任务；检查、修改、构建、测试、自检、证据和后续另行获批的文档、提交、推送或外部操作都在该任务内完成。补充授权继续原任务，不按动作拆任务。
- 角色步骤读取 `.agents/WORKFLOW_PROTOCOL.md`；名额、排队、替代、恢复上限和身份模板读取 `.agents/workflow.json`。
- 按模块读取最近规则和实际入口。活动任务保留无关改动，只在实际环境执行已授权范围。
- 报告执行位置、操作、本轮证据和未覆盖项；计划、代码存在和历史结果不能替代本轮验证。

## 中枢与授权

- 中枢只分析、澄清、设计、编号、创建、等待、协调用户可见执行任务并汇总；不得修改或检查文件、构建、测试、同步文档、提交、推送或执行外部操作。
- 中枢按请求编号并分别确认各动作授权；同一请求的新增授权只转交原执行任务。目标不同的请求按获批顺序排队，活动任务结束前不得物化另一个执行任务。
- 中枢永久存在且不占执行名额；中枢之外最多一个用户可见执行任务，blocked、waiting 或 queued 身份同样占位。任务结果不确定时恢复原身份，不创建替代。
- 中枢身份以当前保存项目绑定的 `.project-flow/hub.json` 为快速入口；正常启动只定向核对登记任务，登记缺失、损坏、冲突或锁恢复时才全量发现。已有初始化锁先按机器契约只读检查；陈旧锁按 owner CAS 恢复同一任务，尚未发布且无任务 ID 的孤儿认领可由当前任务接管，其他锁竞争、身份或项目绑定不确定时停止且不创建替代中枢。
- 任务管理不可用、创建失败、结果不可管理或身份不可确认时停止。禁止中枢回退执行；隐藏子代理不得替代用户可见任务。
- 一次性要求不成为长期授权；文档同步、提交、推送、外部操作和长期机制变更均需明确授权，但授权后仍由原执行任务继续。

## 执行、替代与升级

- 执行任务持续承担同一请求，不因轮次、上下文长度、动作种类或范围确认自动轮换。任何替代、轮换或继任都必须由用户明确授权；授权只允许延续同一请求及已确认边界。
- 中枢确认授权和交接后先归档前任，再创建唯一继任；无真实 ID 时恢复原任务，queued 身份不得重复创建。继任重读规则、核对工作区，历史验证只算历史证据。
- 独立 worktree 仅在存在已授权可传递检查点时替代；缺少明确替代授权时停止并保留原任务。
- `$upgrade-project-flow` 只处理调用任务所属当前保存本地项目。身份或规范路径不匹配时，在读取或操作其他项目前停止。
- 工作流 plan、apply、resume 或 rollback 均由该获批请求唯一的可见任务完成；plan 后补充 apply 授权继续原任务。新 apply/rollback 时，中枢生成一次性 claim ID，以同一精确 claim 启用临时创建屏障并创建或恢复该请求的唯一任务；resume 只恢复已有 claim、屏障和原任务。该任务同时协调事务并执行文件引擎，中枢仍只协调。
- 升级始终穷尽普通、置顶和归档任务的分页元数据；历史只定向读取中枢、升级事务任务、快照活动任务及身份或状态有歧义的候选，元数据不完整或歧义未消除时才回退完整历史读取。
- 快照无活动任务时，事务任务完成文件操作和验证后仅请求一次中枢原始握手并做一次最终元数据穷尽扫描，满足契约即解除屏障。快照非空时，每个替代都先取得用户明确授权；事务任务只归档获准前任并把继任排入中枢队列，事务结束后由中枢逐一创建，不并行物化。
- 插件托管内容采用新版；“项目事实”和项目状态保留；未托管碰撞停止。事务成功后按已部署契约完成中枢和必要继任握手；失败保持屏障，禁止重复事务或角色回退。
- 证据、观察、截止和恢复均按统一协议及机器契约；未完成协调只报告待续。

## 项目状态

- `docs/PROJECT_STATE.md` 只记录当前目标、进展、重要结论和下一步，不提供授权或本轮验证证据。
- 仅在长期状态实质变化且文档同步获授权时使用 `$project-workflow-manager`。

## 交付文档

- 新建或更新的交付文档默认仅使用 `.md`；不得创建独立封面或单独标题页，正文首个非空标题必须是 `#`。
- 标题按层级逐级递进，不得从 `#` 跳到 `###` 等更深层级；正文按内容合理使用段落、列表、表格和代码块。
- 执行任务只校验本次新建或更新的交付文档，不以此授权递归扫描或改写项目中的其他文档。
