# Codex 工作流运行协议

本文件定义 `<PROJECT_NAME>` 的角色步骤。通用授权边界以 `AGENTS.md` 为准；所有精确数值、策略开关和身份模板以 `.agents/workflow.json` 为准。任务只执行与自身角色相符的章节。

## 共同身份与证据

- 当前保存本地项目的精确 `projectId` 和规范路径是唯一边界；按机器模板逐字段生成身份，不得模糊匹配。
- 升级握手和屏障状态只接受已知任务原始 `agentMessage.text` 第一行；等待、摘要、预览、标题、推理、工具输出和提示回显均非证据。
- 身份、边界、能力或结果不可确认时停止；禁止中枢或隐藏代理替代用户可见执行任务。

## 项目中枢

启动时读取 `AGENTS.md`、机器契约、本协议和项目状态，并以当前保存项目精确绑定的 `.project-flow/hub.json` 定向确认自身身份；正常启动不得扫描全部任务。登记缺失、损坏、项目绑定冲突、登记任务不可访问或已有初始化锁时才进入 bootstrap 异常恢复；已有锁先只读检查，陈旧 owner 以原始续租令牌做 CAS，同一旧任务继续恢复，仅 install 阶段未绑定任务且零候选的未发布认领由当前任务原子接管，身份不唯一即停止。中枢只做 `AGENTS.md` 允许的协调动作，每个执行编号创建对应用户可见任务，并依据 `tasks` 与 `execution` 策略管理名额和并发。创建、排队、恢复或身份确认失败时停止，不自行执行。

执行结果通常留在活动任务；需要协调、用户选择或用户明确要求时，中枢才汇总目标、修改、本轮验证、风险与下一步。对已知升级事务任务的当前事务请求，中枢重读已部署规则、核对项目/版本/事务，并按机器模板返回一次原始握手。协调未完成时不得解除屏障或执行文件工作。

## 执行任务轮换

轮换须独立授权，且目标、范围、不做项、环境、验收和已授权动作不变；独立 worktree 还须有已授权可传递检查点，否则返回 Work。轮次门槛读取机器契约。

前任提交代次和任务 ID、执行边界、实际工作区、已完成修改、本轮与历史证据、未覆盖项、剩余步骤、风险、安全点、必读文件及 worktree 检查点；不得复制完整日志或把交接写入项目状态。

中枢确认完整后：

1. 按当前场景的机器模板生成完整继任首行。
2. 先归档已知前任，再创建对应继任。没有真实任务 ID 时恢复前任；排队身份保留同一键等待且不得重建。
3. 继任按完整首行恢复唯一身份，重读规则并核对实际工作区；前任验证仅为历史证据。
4. 普通继任不发送升级握手；升级继任核对版本、事务和代次，再按机器模板返回原始握手。

## 升级协调

升级模式、授权、契约切换和恢复细节以 `$upgrade-project-flow` 的协调契约为准。中枢收到 plan（含 Skill 默认 plan）时创建一个普通可见计划任务，不启用升级屏障；收到 apply 或 rollback 时生成一次性 `claimId`，先按机器模板在自身原始消息记录包含该值的 provisional 状态并立即阻止普通创建，再以同一值创建一个用户可见升级事务任务。resume 从中枢原始屏障消息恢复 claim、状态及唯一精确事务任务，不生成新 claim。中枢不成为事务任务，也不执行文件工作。

1. 事务任务按机器模板认领唯一身份并生成事务键，限定调用任务所属项目；它同时承担可见协调与文件引擎执行角色，不再创建独立执行器。真实任务 ID 恢复后，请求中枢按机器模板记录 active 状态，把临时屏障重绑定到正式事务。
2. 完整分页列出同项目普通、置顶和归档任务的元数据并固定活动快照，把已激活屏障绑定该快照；历史只定向读取中枢、事务任务、快照任务及身份或状态有歧义的候选，元数据不完备或歧义未消除时才回退完整历史读取。
3. 事务任务执行并验证文件操作，成功后切换到已部署或已恢复契约，再请求中枢返回一次原始握手。
4. 空快照走快速路径：中枢握手后只做一次最终元数据穷尽扫描，无需继任、稳定空响应或额外等待，契约满足即解除屏障。
5. 非空快照为每个前任安全交接；不同前任到继任任务对可在可用名额内并行，每对内部严格按归档前任、创建或 fork 继任、确认精确握手串行。任务管理变更不按提交、推送等外部操作串行化；高风险及真正外部操作仍串行。
6. 最终元数据穷尽扫描；仅在事务任务、中枢和所有必要继任精确确认后，请求中枢记录 released 状态并解除屏障。创建确定失败且没有任何任务身份时记录 cancelled；结果不确定时保留 provisional 状态。

阶段进入或恢复时按机器契约穷尽任务元数据并禁用工具输出；历史读取遵循定向优先、歧义时完整回退。等待只负责唤醒，随后仅增量读取相关任务。非空快照在补发、补偿、失败或释放前重新穷尽元数据；相同合法握手幂等折叠。恢复上限和单调截止读取机器契约，原始消息证据规则读取本协议“共同身份与证据”。

到期保留屏障并报告事务、确认项和待续项。恢复时先从已知中枢原始消息读取最新匹配屏障状态，再复用 manifest、事务、任务身份与握手，只继续未决阶段；禁止重复文件事务。身份、消息、管理、验证或恢复失败时保持屏障并停止。
