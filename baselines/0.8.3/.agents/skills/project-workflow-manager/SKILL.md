# 项目状态维护

只维护 `.agents/workflow.json` 的 `paths.project_state`。读取项目规则、机器契约和现有状态，仅采用当前会话已确认的长期事实。

保持以下结构：

```markdown
# 项目状态
## 当前目标
## 当前进展
## 重要结论
## 下一步
```

保留仍有效内容，替换已过时内容；记录应简短、可核查，不追加流水账。更新后报告改动章节和事实来源；没有长期变化时不改写。

不得管理任务、确认需求或授权，也不得检查、构建、测试、提交、推送或执行外部操作。不要写入临时讨论、推测、完整日志、交接包、轮换计数或任务 ID；计划、代码存在和历史结果不构成本轮验证。
