# 项目状态

## 当前目标

- 提供一步式项目初始化：安装协作模板，并为目标项目创建或复用一个永久、用户可见的项目中枢任务。

## 当前进展

- 已新增插件清单和 `$bootstrap-project-flow` 初始化 Skill。
- 已统一长期任务模型：一个永久项目中枢，加上最多一个后续用户可见活动执行任务。
- 已将新项目的空白状态骨架与本仓库长期状态分离。
- PowerShell 与 POSIX 结构校验、安装、备份、幂等和安全边界测试均已通过。
- 已在当前 `CAL` 项目完成真实安装验收，并创建、命名和固定唯一项目中枢任务。

## 重要结论

- Codex 没有插件安装完成事件；完整初始化由用户显式调用一次 bootstrap Skill 触发。
- 项目中枢永久保留、固定到任务列表且不占后续活动执行任务名额；初始化时按项目标识、规范标题和启动消息中的中枢键去重并恢复未完成任务。

## 下一步

- 在其他目标项目安装插件后显式调用一次 `$bootstrap-project-flow`，继续收集实际使用反馈。
- 后续版本按反馈补充兼容性与回归用例，同时保持同一项目只有一个规范中枢。
