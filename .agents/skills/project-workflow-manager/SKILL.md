# 项目状态维护

只维护 `.agents/workflow.json` 中配置的项目状态文件；默认路径为 `docs/PROJECT_STATE.md`。

## 工作方法

1. 读取项目规则、工作流配置和现有项目状态。
2. 只使用当前会话中已确认的事实与实际证据。
3. 将内容归入“当前目标”“当前进展”“重要结论”“下一步”四个章节。
4. 保留仍然有效的内容，删除或改写已被新事实取代的内容，避免追加流水账。
5. 让每条记录简短、可核查；不复制临时讨论、完整日志或未经确认的推测。
6. 更新后报告改动章节和证据来源。

保持状态文件的标题层级，不提升、删除或改名：

```markdown
# 项目状态
## 当前目标
## 当前进展
## 重要结论
## 下一步
```

## 边界

- 不创建、切换、分派或管理任务。
- 不确认需求、范围、接口、环境、验收标准或执行授权。
- 不执行检查、构建、测试、提交、推送或外部操作。
- 不把计划、历史结果或代码存在写成已验证。
- 没有长期状态变化时，不为保持形式而改写文件。
