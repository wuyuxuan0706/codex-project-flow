## Codex Project Flow 集成片段

目标仓库已有根 `AGENTS.md` 时，不自动覆盖或追加。请人工合并以下规则，并保留原项目更具体、更严格的安全、构建和测试约束：

- 需要规则、执行流程或长期状态时，按 `.agents/workflow.json` 读取对应路径。
- Work 只用于只读分析、澄清和设计。
- 修改、检查、构建、测试、文档同步、提交和推送分别列为编号项，只执行用户明确选择的项目。
- 默认最多保留一个用户可见活动任务；阻塞或等待仍占用任务槽。
- 范围、接口、环境或验收标准变化时，停止执行并回到 Work 重新确认。
- 保持改动聚焦，保留并绕开工作区已有的无关改动。
- 区分文档或代码确认、静态检查、实际构建或测试、用户或外部环境回传。
- 未实际运行的检查、构建或测试不得写成通过。
- 高风险操作和外部操作串行执行。
- 一次性要求不自动成为长期规则；修改规则、SOP、Prompt 或 Skill 必须明确授权。
- `docs/PROJECT_STATE.md` 只记录当前目标、当前进展、重要结论和下一步。
- 只有需要协调、要求用户选择或用户明确要求时才回传结果。
