## Codex Project Flow 集成片段

当目标仓库已经存在根 `AGENTS.md` 时，不自动覆盖或追加。请人工合并以下规则，并以原项目更具体的安全、构建和测试约束为准：

- 任务前读取 `.agents/workflow.json`，按其中的文档角色读取项目状态、模块索引、当前任务、风险、决策和周期记录。
- 从实际 README、构建/包清单、局部 `AGENTS.md` 和测试入口发现模块，不假设固定目录结构。
- 用户决定任务方向；没有任务或明确授权来源时，不自行创建任务。
- 只修改当前任务范围，保留工作区已有用户改动。
- 区分“已实现未验证”“本轮实际验证”“用户回传”和“需人工确认”。
- 每次报告验证时写明执行位置、命令、结果和未覆盖项。
- 按 `.agents/workflow.json` 的 `sync_policy` 更新任务、状态、模块、风险、决策和周期记录。
- 未经明确授权，不操作远程系统、生产环境、账号、设备或外部仓库。
